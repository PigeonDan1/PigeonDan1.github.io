Problem definition

不是识别全部内容，
而是找到描述中的声音事件。

目标事件是广义声音事件：可以是一句话、一段对话、人声情绪、音乐变化、环境声音、物体声，或多种听觉线索共同构成的片段。

Phase 0 直接继承 LAT TAG 时间戳，只做确定性的 60 秒内裁剪与相对时间平移，不引入负例，也不重写事件语义。

Minimal protocol

一个输入，唯一答案，两项指标

保持任务定义最小、明确、可复现。

01

INPUT

Mixed audio + query

OUTPUT

  "end": 39.57

秒为单位，满足 0 ≤ start < end ≤ duration。

Reading notes

如何理解当前 Demo

01

它展示金标，不展示模型能力

当前网页用于审阅任务、音频与标注边界；尚未接入任何 baseline 预测。

02

事件类型是 provisional metadata

Speech、Mixed、Non-speech 来自确定性关键词规则，仅用于浏览和切片分析，可继续人工校正。

03

原始时间戳保持不变

审核结论只保存在浏览器并导出为 JSONL；网页不会覆盖 LAT 原始标注或人工复核 manifest。
